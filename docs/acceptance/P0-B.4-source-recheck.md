**Качество источника:** доступность HTML не равна доступности
пользовательского пути; извлечённый текст не доказывает, что строка
видима на всех экранах; `alt` может быть устаревшим. Нет снимков
из реального браузера, сохранённых эталонных DOM/HTTP-заголовков,
проверки форм или согласования с владельцами предприятий. Поэтому
исходные preliminary labels не превращаются автоматически в gold.

**Следующая независимая проверка:** открыть оригинальную страницу
в актуальной версии, отметить дату/регион/что отображалось,
проверить контекст, оспорить или подтвердить предварительное
наблюдение, затем отдельно выбрать статус/обоснование
по слепому пакету. При изменении источника создать новую запись
вместо ретроспективной подмены исходного JSON.
