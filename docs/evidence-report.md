# YA AI Evidence Report v1 — автономный HTML и проверяемые источники

Первый стандартизированный формат отчёта предназначен для **Pain Discovery**.
Он строится только по уже сохранённой карте болей (`pain-map.json`).
**Не вызывает Яндекс, OpenRouter, Jev или другие платные API.**

## Создать отчёт

```bash
npm run report:pain -- \
  --map /private/pain-map.json \
  --html /private/report.html
```

Команда создаёт **два** файла рядом друг с другом:

- `report.html` — автономный интерактивный отчёт, который открывается
  двойным нажатием в браузере, без интернета и отдельного сервера.
- `report.json` — структурированный **YA AI Evidence Report v1**.
  В нём сохранены исходные наблюдения, ссылки на источники, оценки
  модели, версии статусов и связи гипотез с ID свидетельств.

Указать имя JSON отдельно можно через `--json /private/report-data.json`.

Если уже проведена человеческая проверка по [Pain Quality](pain-quality.md):

```bash
npm run report:pain -- \
  --map /private/pain-map.json \
  --quality /private/pain-quality.json \
  --html /private/report-reviewed.html
```

Карта и результат проверки должны иметь **совпадающий fingerprint**.
Недостаточная ручная разметка показывается как недостаточная, а не как
подтверждённое качество модели. Показатели Precision/Recall отображаются
только при статусе `provisional_human_benchmark`, остаются оценкой на
размеченной выборке и **не подтверждают качество на всём рынке**.

## Что показано

1. Основные счётчики: число оценённых наблюдений, категории гипотез,
   отвергнутые ответы модели и принятые ответы, требующие пересмотра.
2. Карточки потенциальных проблем с числом Wordstat-фраз и разных
   страниц в SERP, ссылками на исходные свидетельства и действием для
   следующей **человеческой** проверки.
3. Отдельный блок качества, где отсутствие разметки не маскируется
   красивыми вероятностями Jev.
4. **Полный** журнал: принятые и отвергнутые оценки модели, фрагменты
   источников, URL, регион, исходные частотности. Поиск, фильтры, сортировка,
   скачивание отфильтрованной таблицы в CSV. Для печати предусмотрены стили.
5. Явные ограничения метода, неизвестные величины и отдельно измеренная
   стоимость Jev. Стоимость Яндекса и человеческой разметки не включена.

Наблюдение Wordstat — это поисковая фраза, **не доказанная жалоба
покупателя**. SERP — отрывок из поисковой выдачи, а не подтверждённый полный
текст страницы. Частотности Wordstat пересекаются и **не суммируются**.
Вероятности Jev не являются калиброванной оценкой истинности.

## Проверка целостности

Создатель отчёта **останавливается**, если карта содержит:

- повторяющиеся или неизвестные ID свидетельств, отсутствующее решение Jev;
- несовпадение числа принятых/отвергнутых наблюдений с журналом;
- карточки без соответствующих наблюдений, неверные количества/категории;
- неизвестные отрицательные значения частотности или плохой URL источника;
- человеческий отчёт, сформированный для другой версии Pain Map.

Это проверка **структурной прослеживаемости**, а **не автоматическая
проверка правдивости источника**. Подозрительные утверждения по-прежнему
должны разбирать люди.

Выходные файлы не перезаписываются: запуск с существующим именем выдаёт
ошибку. Генерируйте новую версию под новым именем и датой.

Содержимое источников экранируется в HTML. Страница не загружает
сторонние скрипты, шрифты или аналитику. Ссылки на оригинальные сайты
открываются только при нажатии пользователя. Данные могут быть частными:
**не публикуйте отчёты клиента и не добавляйте их в открытый GitHub**.

## Ограничения текущей версии

Пока это отчёт по **одному** виду исследования, а не универсальный
рендерер всех инструментов YA AI. Общий JSON-контракт и разделение
данных/оформления предназначены для последующего добавления Page Planner,
конкурентной аналитики и инструментов YA AI Studio без повторного
платного исследования.

Готовые статьи и публикация сайта **не** создаются этой командой.

## Проверки

```bash
node scripts/evidence-report-selftest.mjs
npm run check
```

Тесты используют синтетические наблюдения и проверяют целостность, XSS,
сохранение отрицательных ответов, отказ от перезаписи файлов и работу
генератора без API-ключей и сетевых вызовов. Они не заменяют реальный
визуальный просмотр HTML в браузере.
